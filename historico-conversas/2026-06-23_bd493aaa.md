## 🤖 Claude

Boa pergunta — e a resposta curta é: **não dá pra "conectar" um no outro, porque os dois são o mesmo *tipo* de coisa.** Cursor e Antigravity são ambos **IDEs (editores) concorrentes**, os dois forks do VS Code. Você usa um OU outro, não um dentro do outro.

## O que cada um é

| | **Antigravity** | **Cursor** |
|---|---|---|
| Quem faz | Google | Anysphere |
| Modelo "nativo" | Gemini (família Gemini 3) | Agnóstico — você liga sua chave/conta (Claude, GPT, Gemini…) |
| Base | Fork do VS Code | Fork do VS Code |
| Pegada | Agêntico de primeira (foco em agentes que rodam tarefas, "manager view") | Editor com IA muito forte no fluxo de código (tab, edit, chat, agent) |
| Maturidade | Mais novo (lançado fim de 2025) | Mais consolidado, base grande de usuários |

## Por que "conectar" não faz sentido
São duas aplicações separadas que disputam o mesmo lugar na sua máquina. Não existe um plugin "Cursor dentro do Antigravity" nem vice-versa. O que **dá** pra fazer:

- **Abrir o mesmo repositório** nos dois (já que ambos leem uma pasta de projeto normal do Git). Você pode editar a mesma pasta ora no Cursor, ora no Antigravity — só não ao mesmo tempo sem cuidado com conflito de arquivo.
- **Levar extensões do VS Code** pra qualquer um dos dois (os dois aceitam extensões via marketplace, com algumas limitações).
- **Reusar suas configs** (settings.json, keybindings) copiando entre eles, porque a base é a mesma.

## Como escolher pro seu caso
Você já tá rodando o **Antigravity** aqui (esse scratch é dele) e seu fluxo é forte em agentes — skills do Laxtro, video-use, staging via Remote-SSH. Pra esse estilo "agente faz a tarefa", o Antigravity encaixa bem. O Cursor brilha mais quando você quer **editar código manualmente com IA ajudando linha a linha** e escolher livremente o modelo.
