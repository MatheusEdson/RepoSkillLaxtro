## O que ele faz

**Primeira coisa que sempre pergunta:** qual site e qual plataforma — porque o playbook muda por stack.

**Plataformas que ele domina:**
- **WordPress** (Blips / clientes 2B) — LiteSpeed + Cloudflare, 8 mu-plugins de Core Web Vitals, hardening
- **React SPA** (matheusedson.com — o "gold standard" dele) — Vite + Nginx + Docker Swarm + Traefik
- **Next.js / Astro / Static** — boas práticas por default

**Quatro frentes principais:**

1. **DevOps / Infra** — deploy, Docker, Nginx, pipeline de build, troubleshooting de cache (LiteSpeed bugs conhecidos com Elementor/GravityForms)
2. **Performance** — CWV (LCP/CLS/INP/TTFB), os mu-plugins do "Blips Arsenal" (case real: PageSpeed 47→89 em 2 semanas em 9 sites)
3. **Segurança** — hardening WP via mu-plugins, detecção de webshells (5 greps), auditoria de backdoors MySQL por trigger, checklist Docker/Nginx
4. **GEO/SEO** — o diferencial: otimizar pra **citação por IA** (llms.txt, robots.txt com a distinção `ClaudeBot` vs `Claude-SearchBot`, JSON-LD/FAQPage, AI readability)

**Bônus embutido:** todo o **pipeline de conteúdo LinkedIn do Matheus Edson** (calendário de posts, iscas/lead magnets, render de PNGs, engagement playbook 2-3-1).
